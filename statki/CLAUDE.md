# CLAUDE.md

The rules for talking to Jaś, building and code style are in `../CLAUDE.md`. This file describes only this game.

## The game

Statki: the classic Polish battleship game for the whole family, played together in the same Wi-Fi on phones and computers, with any number of players (at least two). Everyone types a name in the lobby, anyone presses Start, each player places a fleet on their own 10x10 board, then players shoot in turn at any opponent's board. A hit (or a sunk ship) gives another shot, a miss passes the turn. A player who loses all ships is out; the last one with ships wins. Everyone sees every board's shots; only your own unhit ships are visible to you until the game ends, when all ships are revealed.

Two board sizes, picked by anyone in the lobby: Klasyczna (10x10 board; one 4-mast, two 3-masts, three 2-masts, four 1-masts, Polish rules) and Szybka (7x7 board; ships 3, 2, 2, 1, 1) for a quick game. Ships may not touch, not even at corners. Water around a sunk ship is marked automatically.

Two ways to win, also picked by anyone in the lobby (everyone sees the same choice). Klasycznie is the default and is unchanged: a hit gives another shot, a miss passes the turn, a player with no ships is out, the last fleet wins. Na punkty: the same shooting (a hit still gives another shot; one round is one such turn for every player still in the game), 1 point per hit cell plus a bonus equal to the ship's length when it sinks, so a 1-mast is 2 points and a 4-mast is 8. Auto-marked water around a wreck is not a shot and scores nothing. The game lasts 5, 10 (default) or 15 rounds, or ends at once when only one fleet still has ships. A sunk fleet is not a target anymore, but that player keeps shooting and scoring until the game ends. Highest score wins, even with no ships left. A tie on points goes to better accuracy (hits divided by shots fired). If accuracy ties too, they share the place. `mise run test` checks the rules.

If someone joined but is not really playing, any real player (not a spectator) can press "Zacznij od nowa" in the lobby, while placing ships, or during the battle. A box then asks "Tak, od nowa" (or "Nie"), so it is not an accident. Every connected player is dropped from the round and sees the Gram! screen; only those who tap Gram! enter the lobby. The lobby and the ship-placing screen list who is still pending. "Nowa gra" at the end still keeps the connected players, as before.

## How to run

- `mise run serwer` - runs `serwer.js` on port 8081 (Kraina Wiśni uses 8080, so both can run) for the whole home network, opens the game in the browser and prints the address for phones. Every saved file (except `serwer.js`) reloads the page in all browsers; the game itself lives on the server and continues. Changing `serwer.js` needs a server restart, which ends the current game.
- `mise run wdroz` - deploys to a home server over SSH; the private settings (`SERWER` ssh host name, `DOMENA`, `PORT_PUBLICZNY`) live in `mise.local.toml` and the server details in `CLAUDE.local.md`, both kept out of git. Two Docker containers on the network `gry`, both `--restart unless-stopped`:
  - `statki` (`node:22-alpine`) runs `serwer.js` from `/srv/statki` (mounted read-only) on internal port 8081 with `PUBLICZNY_ADRES` set to `https://$DOMENA:$PORT_PUBLICZNY`; it publishes no port. Recreated only when `serwer.js`/`zasady.js` changed, the address changed, or it is not running; otherwise browsers just reload and the running game continues.
  - `caddy` (`caddy:2-alpine`) with `wdrozenie/Caddyfile` (copied to `/srv/caddy/Caddyfile`, reloaded on each deploy; `{$DOMENA}` and `{$PORT_PUBLICZNY}` come from the container environment) terminates HTTPS and proxies to `statki:8081`. It obtains and renews its own Let's Encrypt certificate with the HTTP-01 challenge on port 80. The public address is HTTPS, so plain HTTP is not an option for that site. A new game on the same server = one more site block in the Caddyfile on its own port, published on the `caddy` container.
  - The server reads `PORT` and `PUBLICZNY_ADRES` from the environment.
  - Everything in `/srv/statki` is served to the public, so the deploy leaves out `wdrozenie/`, `.claude/`, `CLAUDE.local.md` and `mise.local.toml`.
- There is no single-player mode: opened from disk, `index.html` only says to start the server.

## Code structure

HTML elements instead of a canvas (a board game needs crisp grids and buttons that work the same with a mouse and a finger). The server decides everything; the browser only draws what the server sends and sends the player's moves.

- `zasady.js` - rules shared by browser and server (`module.exports` when loaded by Node): `TRYBY` (board sizes: `nazwa`, `opis`, `rozmiar`, `statki` lengths; add a new type here), `SPOSOBY` (`klasyczny` / `punkty`), `RUNDY_DO_WYBORU` and `RUNDY_DOMYSLNIE`, `punktyZaStrzal(wynik, dlugosc)`, `ranking(lista)` (points, then accuracy, shared place on a full tie), `LITERY`, `nazwaPola(pole, rozmiar)` (field = row * rozmiar + column, shown as "B5"), `sasiedzi(pole, rozmiar)`, `zbudujFlote(lista, tryb, calaFlota)` (validates bounds, overlap, touching and, for a full fleet, the ship lengths; returns `{ statki, naPolu }` or null), `losujFlote(tryb)`. `test.js` checks this plus a real server game (`mise run test`).
- `serwer.js` - Node, built-in modules only. State `gra`: `etap` (`poczekalnia` -> `ustawianie` -> `bitwa` -> `koniec`), `tryb` (key of `TRYBY`; `tryb()` and `ilePol()` give the current board), `sposob` (`klasyczny` or `punkty`), `ileRund`, `runda`, `kolejka` (whose turn is still left this round, points mode only), `gracze` (secret `id`, public `nr`, `imie`, `online`, `offlineOd`, `widz` spectator who joined mid-game, `gotowy`, `odpadl`, `statki`, `naPolu`, `strzaly` 0 none / 1 miss / 2 hit / 3 sunk, and for points `punkty`, `trafienia`, `oddane`), `tura` (nr of the shooter), `dziennik`, `ostatni` (last shot with a growing `numer` and a ready-made `tekst`). Actions arrive as POST `/akcja` `{ id, typ, ... }`: `dolacz`, `tryb` (lobby only, clears boards), `sposob` and `rundy` (lobby only; rounds must be 5, 10 or 15), `start` (drops disconnected players, needs 2+), `ustaw` (full fleet; when all are ready the battle starts with a random player), `strzal`, `usun` (only a player offline for `SEKUNDY_DO_USUNIECIA`; in battle they are marked out, otherwise removed), `nowaGra`, `odNowa` (any joined non-spectator, any stage; a second tap from someone already waiting is ignored). `odNowa` sets `etap` back to `poczekalnia`, clears boards, the turn and the log, and moves every current player plus anyone already waiting into `oczekujacy` (`id`, `imie`) so an idle phone cannot auto-rejoin. It keeps `tryb`, `sposob` and `ileRund`. `dolacz` removes that id from `oczekujacy`. In points mode a sunk fleet does not set `odpadl` and that player stays in the turn order; `odpadl` is only for a player removed while offline. Errors come back as `{ blad }` in Polish. Each browser keeps an `EventSource` on `/wydarzenia?id=` and gets its own `stan` view from `widokDla(id)` (with `tryb`, `sposob`, `runda`, `ileRund`, `ranking` when playing for points, `trzebaPotwierdzic` when this browser is still in `oczekujacy`, and `oczekujacy`: the other waiting names with `online`, no secret ids): every board as a string of rozmiar² characters (0 water, 1 miss, 2 hit, 3 sunk, 4 own unhit ship, all ships at the end). Also serves the files (no hidden files, nothing outside the folder) and sends `odswiez` on file changes.
- `game.js` - browser. `mojeId` in `localStorage` (prefix `statki-`) makes a reconnect, a reload or a server restart rejoin as the same player under the saved name; if the `EventSource` gives up (`CLOSED`), `polacz()` starts a new one after 2 s. A saved name auto-sends `dolacz` when `stan.ja` is 0, except when `stan.trzebaPotwierdzic` is set: then `ekranGram` waits for the Gram! tap. `tryb()` returns the current rules from `stan.tryb`; boards size their grid columns from it. `reaguj()` turns server changes into sounds, the result bubble `#dymek`, vibration when your ship is hit, the "your turn" chime, and `wybuchDo` (the newest shot's cell gets class `wybuch` for one animation). `rysuj()` picks a screen (`ekranImie`, `ekranLaczenie`, `ekranGram`, `ekranPoczekalnia`, `ekranUstawianie`, `ekranBitwa`; `ekranPlik` when opened from disk). `zrobPlansze(pola, opcje)` builds a board grid. Placement (`ustawianie`) stays local until "Gotowe": pick a ship, tap a cell, tap a placed ship to take it back, ↻ (or R) rotates, 🎲 random, hover preview on desktop. The preview only recolours existing cells (`klasyPodgladu` from `najedzUstawianie`). Rebuilding the board on that hover makes Safari drop the click: on iPhone a tap fires mouseenter first and the ship never lands, and a click after the preview is lost on desktop Safari too. In battle opponents' boards come first and are clickable on your turn; `strzel` sends one shot at a time. Points mode draws `#sposoby` and `#rundy` in the lobby and `rysujTablice()` from `stan.ranking`; a sunk fleet is not clickable.
- `dzwieki.js` - Web Audio sounds: shot whistle, miss splash (`dzwiekPlusk`: low "plum" with a rising bubble, soft falling-pitch noise of the splash, then random quiet droplets via `babelek`), explosion, sinking, turn chime, click.
- `index.html` / `style.css` - all screens, board buttons (`#tryby`), who-wins buttons (`#sposoby`) and, only for Na punkty, round buttons (`#rundy`, hidden in the classic lobby) plus rules text; during a points battle `#tablica` (inside the sticky `#tura` bar) shows the round and the live scores, and at the end `#ranking` lists places with points and hits out of shots. Boards are `min(92vw, 340px)` wide and wrap, the turn bar sticks to the top on phones. Two looks, switched by the header button and remembered as `statki-wyglad` in `localStorage`. Default `kartka` is a squared notebook sheet: off-white paper, a red margin, light blue grid lines, column letters and row numbers in a handwriting font, ships as one pen outline (`krawedzGora` / `krawedzDol` / `krawedzLewo` / `krawedzPrawo`, added when the board is built), a miss as a small circle, a hit as an X, a sunk ship as a red pen outline with a bigger X. The result bubble sits at the bottom so it does not cover the turn line; the winner line is a yellow highlighter (`koniecGry`). `morze` is the previous sea look: water blue, miss 💦, hit orange ✖, sunk dark red ✖, own ship grey. The newest shot has a yellow outline and a one-time ring animation. The handwriting font is Patrick Hand in `czcionki/` (SIL OFL, `czcionki/OFL.txt`), so it loads with no internet; Segoe Print, Comic Sans and Chalkboard SE are the fallback. `serwer.js` serves `.woff2` as `font/woff2`.

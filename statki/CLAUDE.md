# CLAUDE.md

The rules for talking to Jaś, building and code style are in `../CLAUDE.md`. This file describes only this game.

## The game

Statki: the classic Polish battleship game for the whole family, played together in the same Wi-Fi on phones and computers, with any number of players (at least two). Everyone types a name in the lobby, anyone presses Start, each player places a fleet on their own 10x10 board, then players shoot in turn at any opponent's board. A hit (or a sunk ship) gives another shot, a miss passes the turn. A player who loses all ships is out; the last one with ships wins. Everyone sees every board's shots; only your own unhit ships are visible to you until the game ends, when all ships are revealed.

Two game types, picked by anyone in the lobby: Klasyczna (10x10 board; one 4-mast, two 3-masts, three 2-masts, four 1-masts, Polish rules) and Szybka (7x7 board; ships 3, 2, 2, 1, 1) for a quick game. Ships may not touch, not even at corners. Water around a sunk ship is marked automatically.

If someone joined but is not really playing, any real player (not a spectator) can press "Zacznij od nowa" in the lobby, while placing ships, or during the battle. A box then asks "Tak, od nowa" (or "Nie"), so it is not an accident. Every connected player is dropped from the round and sees the Gram! screen; only those who tap Gram! enter the lobby. The lobby and the ship-placing screen list who is still pending. "Nowa gra" at the end still keeps the connected players in the same lobby, as before. "Wyjdź" leaves this lobby and goes back to the start screen (not during a battle, unless you are only watching).

Several games run on this one server at the same time. The start screen (`ekranStart`) has "Nowa gra" and "Dołącz kodem". "Nowa gra" can take an own code (letters and digits, 3–8 characters; Polish letters are folded, so Jaś1 becomes jas1; upper and lower case are the same). An empty field gets a short word or name from `SLOWA_KODOW` plus a digit 1–9, for example jas1 or ala3. If that code is already a lobby, the server says so in simple Polish and does not open the other game. The code is shown big in the lobby (and spelled underneath), in the header during the game, and as a link `?kod=jas1`. A missing or bad code gets a short Polish message. Lobbies do not share players, boards, turns, the restart list or the log. A lobby with nobody connected is deleted after 15 minutes so a small computer (Raspberry Pi 2) does not keep old games. `SEKUNDY_PUSTEGO_LOBBY` overrides that for tests. At most 40 lobbies.

When the battle ends, the end screen shows statistics kept on the server for that lobby only: who shot at whom, shots, hits, misses, accuracy, which ships each player sank and whose, and awards (Snajper for the best accuracy, Pechowiec for the most misses, Seria for the longest run of hits, Pogromca for the most ships sunk). A shot in one code does not change another code. Rings of water drawn around a sunk ship are not counted as shots. The numbers reset on Start, on "Nowa gra", and on "Zacznij od nowa" inside that lobby.

## How to run

- `mise run serwer` - runs `serwer.js` on port 8081 (Kraina Wiśni uses 8080, so both can run) for the whole home network, opens the game in the browser and prints the address for phones. Every saved file (except `serwer.js`) reloads the page in all browsers; the game itself lives on the server and continues. Changing `serwer.js` needs a server restart, which ends the current game.
- `mise run wdroz` - deploys to a home server over SSH; the private settings (`SERWER` ssh host name, `DOMENA`, `PORT_PUBLICZNY`) live in `mise.local.toml` and the server details in `CLAUDE.local.md`, both kept out of git. Two Docker containers on the network `gry`, both `--restart unless-stopped`:
  - `statki` (`node:22-alpine`) runs `serwer.js` from `/srv/statki` (mounted read-only) on internal port 8081 with `PUBLICZNY_ADRES` set to `https://$DOMENA:$PORT_PUBLICZNY`; it publishes no port. Recreated only when `serwer.js`/`zasady.js` changed, the address changed, or it is not running; otherwise browsers just reload and the running game continues.
  - `caddy` (`caddy:2-alpine`) with `wdrozenie/Caddyfile` (copied to `/srv/caddy/Caddyfile`, reloaded on each deploy; `{$DOMENA}` and `{$PORT_PUBLICZNY}` come from the container environment) terminates HTTPS and proxies to `statki:8081`. It obtains and renews its own Let's Encrypt certificate with the HTTP-01 challenge on port 80. Browsers force HTTPS on `.dev` domains, so plain HTTP is not an option there. A new game on the same server = one more site block in the Caddyfile on its own port, published on the `caddy` container.
  - The server reads `PORT`, `PUBLICZNY_ADRES` and optional `SEKUNDY_PUSTEGO_LOBBY` from the environment.
  - Everything in `/srv/statki` is served to the public, so the deploy leaves out `wdrozenie/`, `.claude/`, `CLAUDE.local.md` and `mise.local.toml`.
- `mise run testy` - checks that two lobbies do not mix (joins, shots, restart, a wrong code, and that an empty lobby disappears), and that end-of-game stats stay inside their own code.
- There is no single-player mode: opened from disk, `index.html` only says to start the server.

## Code structure

HTML elements instead of a canvas (a board game needs crisp grids and buttons that work the same with a mouse and a finger). The server decides everything; the browser only draws what the server sends and sends the player's moves.

- `zasady.js` - rules shared by browser and server (`module.exports` when loaded by Node): `TRYBY` (game types: `nazwa`, `opis`, `rozmiar`, `statki` lengths; add a new type here), `LITERY`, `nazwaPola(pole, rozmiar)` (field = row * rozmiar + column, shown as "B5"), `sasiedzi(pole, rozmiar)`, `zbudujFlote(lista, tryb, calaFlota)` (validates bounds, overlap, touching and, for a full fleet, the ship lengths; returns `{ statki, naPolu }` or null), `losujFlote(tryb)`. Also the lobby code: `SLOWA_KODOW`, `oczyscKod(tekst)` (lowercase, strips Polish diacritics, keeps letters and digits), `kodWygladaDobrze(kod)` (3–8 of those), `losujKodGry(zajete)` (word plus a digit 1–9 that is not already taken).
- `serwer.js` - Node, built-in modules only. Many lobbies: `lobby[kod]` is one game. `pustaGra(kod)` is that game's whole state, and every rule function takes this `gra`, so a new field (scores, a picture, a mode) stays inside the lobby instead of leaking across games. `gra`: `kod`, `etap` (`poczekalnia` -> `ustawianie` -> `bitwa` -> `koniec`), `tryb` (key of `TRYBY`; `tryb(gra)` and `ilePol(gra)` give the current rules), `gracze` (secret `id`, public `nr`, `imie`, `online`, `offlineOd`, `widz` spectator who joined mid-game, `gotowy`, `odpadl`, `statki`, `naPolu`, `strzaly` 0 none / 1 miss / 2 hit / 3 sunk, `stat` with this lobby's shots, hits, misses, best hit streak, ships sunk and a who→whom tally), `oczekujacy`, `tura` (nr of the shooter), `dziennik`, `ostatni` (last shot with a growing `numer` and a ready-made `tekst`), `numerStrzalu`, `nastepnyNumer` (per lobby), `sluchacze` (this lobby's open connections only), `ostatnio` (for cleanup). Actions arrive as POST `/akcja` `{ id, kod, typ, ... }`: `noweLobby` (returns `{ kod }`), `sprawdzKod`, then inside that lobby `dolacz`, `tryb` (lobby only, clears boards), `start` (drops disconnected players, needs 2+), `ustaw` (full fleet; when all are ready the battle starts with a random player), `strzal`, `usun` (only a player offline for `SEKUNDY_DO_USUNIECIA`; in battle they are marked out, otherwise removed), `nowaGra` (same lobby, after the end), `odNowa` (any joined non-spectator, any stage; a second tap from someone already waiting is ignored), `wyjdz` (leave this lobby; during a battle only a spectator may). `odNowa` sets `etap` back to `poczekalnia`, clears boards, the turn and the log, and moves every current player plus anyone already waiting into `oczekujacy` (`id`, `imie`) so an idle phone cannot auto-rejoin. `dolacz` removes that id from `oczekujacy`. Errors come back as `{ blad }` in Polish. Each browser keeps an `EventSource` on `/wydarzenia?id=&kod=` and gets its own `stan` view from `widokDla(gra, id)` (with `kod`, `tryb`, `trzebaPotwierdzic` when this browser is still in `oczekujacy`, and `oczekujacy`: the other waiting names with `online`, no secret ids): every board as a string of rozmiar² characters (0 water, 1 miss, 2 hit, 3 sunk, 4 own unhit ship, all ships at the end). `statystyki` is null until this lobby's `koniec`, then it is that lobby's public numbers plus awards (no secret ids). `wyczyscPlansze` clears `stat`, so Start and Nowa gra reset this lobby's tally; Zacznij od nowa drops this lobby's players and the tally with them. No code, or a code that is not a live lobby, gets `{ ekran: "start" }` or `{ brakGry, kod, tekst }` and still receives `odswiez`. The same player id can sit in two lobbies at once (two browser windows). Also serves the files (no hidden files, nothing outside the folder) and sends `odswiez` on file changes. Empty lobbies are removed by `posprzataj` (nobody connected for `SEKUNDY_PUSTEJ_GRY`, default 15 minutes).
- `game.js` - browser. `mojeId` in `localStorage` (prefix `statki-`) makes a reconnect, a reload or a server restart rejoin as the same player under the saved name; if the `EventSource` gives up (`CLOSED`), `polacz()` starts a new one after 2 s. A saved name auto-sends `dolacz` when `stan.ja` is 0, except when `stan.trzebaPotwierdzic` is set: then `ekranGram` waits for the Gram! tap. `tryb()` returns the current rules from `stan.tryb`; boards size their grid columns from it. `reaguj()` turns server changes into sounds, the result bubble `#dymek`, vibration when your ship is hit, the "your turn" chime, and `wybuchDo` (the newest shot's cell gets class `wybuch` for one animation). `kodGry` comes from `?kod=` (cleaned by `oczyscKod`). No code: `ekranStart` ("Nowa gra" creates a lobby and opens `?kod=`, "Dołącz kodem" checks the code first, "Wróć do gry" uses the last code in `localStorage`). `wyslij` adds `kod`. A saved name still auto-sends `dolacz` only inside a real lobby, and not when `stan.trzebaPotwierdzic` is set. `rysuj()` picks a screen (`ekranStart`, `ekranImie`, `ekranLaczenie`, `ekranGram`, `ekranPoczekalnia`, `ekranUstawianie`, `ekranBitwa`; `ekranPlik` when opened from disk). The lobby shows `#kodDuzy`, the spelled letters and the join link; `#kodWNaglowku` shows the code once you are in. `zrobPlansze(pola, opcje)` builds a board grid. Placement (`ustawianie`) stays local until "Gotowe": pick a ship, tap a cell, tap a placed ship to take it back, ↻ (or R) rotates, 🎲 random, hover preview on desktop. The preview only recolours existing cells (`klasyPodgladu` from `najedzUstawianie`). Rebuilding the board on that hover makes Safari drop the click: on iPhone a tap fires mouseenter first and the ship never lands, and a click after the preview is lost on desktop Safari too. In battle opponents' boards come first and are clickable on your turn; `strzel` sends one shot at a time. On the end screen `rysujStatystyki` fills `#statystyki` from this lobby's `stan.statystyki` (awards, who-shot-whom table, a card per player). Award names live in `NAZWY_ODZNAK`.
- `dzwieki.js` - Web Audio sounds: shot whistle, miss splash (`dzwiekPlusk`: low "plum" with a rising bubble, soft falling-pitch noise of the splash, then random quiet droplets via `babelek`), explosion, sinking, turn chime, click.
- `index.html` / `style.css` - all screens, game type buttons (`#tryby`) and rules text in the lobby; boards are `min(92vw, 340px)` wide and wrap, the turn bar sticks to the top on phones. Two looks, switched by the header button and remembered as `statki-wyglad` in `localStorage`. Default `kartka` is a squared notebook sheet: off-white paper, a red margin, light blue grid lines, column letters and row numbers in a handwriting font, ships as one pen outline (`krawedzGora` / `krawedzDol` / `krawedzLewo` / `krawedzPrawo`, added when the board is built), a miss as a small circle, a hit as an X, a sunk ship as a red pen outline with a bigger X. The result bubble sits at the bottom so it does not cover the turn line; the winner line is a yellow highlighter (`koniecGry`). The end-screen stats (`#statystyki`) sit on the same sheet: dashed blue frame, highlighter title, pastel award chips, a scrolling who→whom table and a card per player. In the sea theme the same block is a dark translucent card with the same chips, so the numbers stay readable. `morze` is the previous sea look: water blue, miss 💦, hit orange ✖, sunk dark red ✖, own ship grey. The newest shot has a yellow outline and a one-time ring animation. The handwriting font is Patrick Hand in `czcionki/` (SIL OFL, `czcionki/OFL.txt`), so it loads with no internet; Segoe Print, Comic Sans and Chalkboard SE are the fallback. `serwer.js` serves `.woff2` as `font/woff2`.

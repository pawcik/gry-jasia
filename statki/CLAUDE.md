# CLAUDE.md

The rules for talking to Jaś, building and code style are in `../CLAUDE.md`. This file describes only this game.

## The game

Statki: the classic Polish battleship game for the whole family, played together in the same Wi-Fi on phones and computers, with any number of players (at least two). Everyone types a name in the lobby, anyone presses Start, each player places a fleet on their own 10x10 board, then players shoot in turn at any opponent's board. A hit (or a sunk ship) gives another shot, a miss passes the turn. A player who loses all ships is out; the last one with ships wins. Everyone sees every board's shots; only your own unhit ships are visible to you until the game ends, when all ships are revealed.

Two game types, picked by anyone in the lobby: Klasyczna (10x10 board; one 4-mast, two 3-masts, three 2-masts, four 1-masts, Polish rules) and Szybka (7x7 board; ships 3, 2, 2, 1, 1) for a quick game. Ships may not touch, not even at corners. Water around a sunk ship is marked automatically.

## How to run

- `mise run serwer` - runs `serwer.js` on port 8081 (Kraina Wiśni uses 8080, so both can run) for the whole home network, opens the game in the browser and prints the address for phones. Every saved file (except `serwer.js`) reloads the page in all browsers; the game itself lives on the server and continues. Changing `serwer.js` needs a server restart, which ends the current game.
- `mise run wdroz` - deploys to a home server over SSH; the private settings (`SERWER` ssh host name, `DOMENA`, `PORT_PUBLICZNY`) live in `mise.local.toml` and the server details in `CLAUDE.local.md`, both kept out of git. Two Docker containers on the network `gry`, both `--restart unless-stopped`:
  - `statki` (`node:22-alpine`) runs `serwer.js` from `/srv/statki` (mounted read-only) on internal port 8081 with `PUBLICZNY_ADRES` set to `https://$DOMENA:$PORT_PUBLICZNY`; it publishes no port. Recreated only when `serwer.js`/`zasady.js` changed, the address changed, or it is not running; otherwise browsers just reload and the running game continues.
  - `caddy` (`caddy:2-alpine`) with `wdrozenie/Caddyfile` (copied to `/srv/caddy/Caddyfile`, reloaded on each deploy; `{$DOMENA}` and `{$PORT_PUBLICZNY}` come from the container environment) terminates HTTPS and proxies to `statki:8081`. It obtains and renews its own Let's Encrypt certificate with the HTTP-01 challenge on port 80. Browsers force HTTPS on `.dev` domains, so plain HTTP is not an option there. A new game on the same server = one more site block in the Caddyfile on its own port, published on the `caddy` container.
  - The server reads `PORT` and `PUBLICZNY_ADRES` from the environment.
  - Everything in `/srv/statki` is served to the public, so the deploy leaves out `wdrozenie/`, `.claude/`, `CLAUDE.local.md` and `mise.local.toml`.
- There is no single-player mode: opened from disk, `index.html` only says to start the server.

## Code structure

HTML elements instead of a canvas (a board game needs crisp grids and buttons that work the same with a mouse and a finger). The server decides everything; the browser only draws what the server sends and sends the player's moves.

- `zasady.js` - rules shared by browser and server (`module.exports` when loaded by Node): `TRYBY` (game types: `nazwa`, `opis`, `rozmiar`, `statki` lengths; add a new type here), `LITERY`, `nazwaPola(pole, rozmiar)` (field = row * rozmiar + column, shown as "B5"), `sasiedzi(pole, rozmiar)`, `zbudujFlote(lista, tryb, calaFlota)` (validates bounds, overlap, touching and, for a full fleet, the ship lengths; returns `{ statki, naPolu }` or null), `losujFlote(tryb)`.
- `serwer.js` - Node, built-in modules only. State `gra`: `etap` (`poczekalnia` -> `ustawianie` -> `bitwa` -> `koniec`), `tryb` (key of `TRYBY`; `tryb()` and `ilePol()` give the current rules), `gracze` (secret `id`, public `nr`, `imie`, `online`, `offlineOd`, `widz` spectator who joined mid-game, `gotowy`, `odpadl`, `statki`, `naPolu`, `strzaly` 0 none / 1 miss / 2 hit / 3 sunk), `tura` (nr of the shooter), `dziennik`, `ostatni` (last shot with a growing `numer` and a ready-made `tekst`). Actions arrive as POST `/akcja` `{ id, typ, ... }`: `dolacz`, `tryb` (lobby only, clears boards), `start` (drops disconnected players, needs 2+), `ustaw` (full fleet; when all are ready the battle starts with a random player), `strzal`, `usun` (only a player offline for `SEKUNDY_DO_USUNIECIA`; in battle they are marked out, otherwise removed), `nowaGra`; errors come back as `{ blad }` in Polish. Each browser keeps an `EventSource` on `/wydarzenia?id=` and gets its own `stan` view from `widokDla(id)` (with `tryb`): every board as a string of rozmiar² characters (0 water, 1 miss, 2 hit, 3 sunk, 4 own unhit ship, all ships at the end). Also serves the files (no hidden files, nothing outside the folder) and sends `odswiez` on file changes.
- `game.js` - browser. `mojeId` in `localStorage` (prefix `statki-`) makes a reconnect, a reload or a server restart rejoin as the same player under the saved name; if the `EventSource` gives up (`CLOSED`), `polacz()` starts a new one after 2 s. `tryb()` returns the current rules from `stan.tryb`; boards size their grid columns from it. `reaguj()` turns server changes into sounds, the result bubble `#dymek`, vibration when your ship is hit, the "your turn" chime, and `wybuchDo` (the newest shot's cell gets class `wybuch` for one animation). `rysuj()` picks a screen (`ekranImie`, `ekranLaczenie`, `ekranPoczekalnia`, `ekranUstawianie`, `ekranBitwa`; `ekranPlik` when opened from disk). `zrobPlansze(pola, opcje)` builds a board grid. Placement (`ustawianie`) stays local until "Gotowe": pick a ship, tap a cell, tap a placed ship to take it back, ↻ (or R) rotates, 🎲 random, hover preview on desktop. In battle opponents' boards come first and are clickable on your turn; `strzel` sends one shot at a time.
- `dzwieki.js` - Web Audio sounds: shot whistle, miss splash (`dzwiekPlusk`: low "plum" with a rising bubble, soft falling-pitch noise of the splash, then random quiet droplets via `babelek`), explosion, sinking, turn chime, click.
- `index.html` / `style.css` - all screens, game type buttons (`#tryby`) and rules text in the lobby; boards are `min(92vw, 340px)` wide and wrap, the turn bar sticks to the top on phones. Cell look: water blue, miss 💦, hit orange ✖, sunk dark red ✖, own ship grey; the newest shot has a yellow outline and a one-time ring animation (white splash on water, orange on a hit).

# CLAUDE.md

The rules for talking to Jaś, building and code style are in `../CLAUDE.md`. This file describes only this game.

## The game

Statki: the classic Polish battleship game for the whole family, played together in the same Wi-Fi on phones and computers, with any number of players (at least two). Everyone types a name in the lobby, anyone presses Start, each player places a fleet on their own 10x10 board, then players shoot in turn at any opponent's board. A hit (or a sunk ship) gives another shot, a miss passes the turn. A player who loses all ships is out; the last one with ships wins. Everyone sees every board's shots; only your own unhit ships are visible to you until the game ends, when all ships are revealed.

Two game types, picked by anyone in the lobby: Klasyczna (10x10 board; one 4-mast, two 3-masts, three 2-masts, four 1-masts, Polish rules) and Szybka (7x7 board; ships 3, 2, 2, 1, 1) for a quick game. Ships may not touch, not even at corners. Water around a sunk ship is marked automatically.

If someone joined but is not really playing, any real player (not a spectator) can press "Zacznij od nowa" in the lobby, while placing ships, or during the battle. A box then asks "Tak, od nowa" (or "Nie"), so it is not an accident. Every connected player is dropped from the round and sees the Gram! screen; only those who tap Gram! enter the lobby. The lobby and the ship-placing screen list who is still pending. "Nowa gra" at the end still keeps the connected players, as before.

On the name screen each player picks one of ten original little blue gnomes in a white floppy cap (Śpioch, Łasuch, Kucharz, Mądrala, Siłacz, Maruda, Wesołek, Malarz, Pirat, Kapitan). They are drawn in the game, not taken from any cartoon. The choice is remembered on the device as `statki-awatar`. If nothing was saved, the browser picks one at random. Two players may pick the same one. The face is sent with `dolacz` and shown in the header, the Gram! screen, the lobby, the waiting list, while placing ships, on each board in the battle, and on the winner line.

## How to run

- `mise run serwer` - runs `serwer.js` on port 8081 (Kraina Wiśni uses 8080, so both can run) for the whole home network, opens the game in the browser and prints the address for phones. Every saved file (except `serwer.js`) reloads the page in all browsers; the game itself lives on the server and continues. Changing `serwer.js` needs a server restart, which ends the current game.
- `mise run wdroz` - deploys to a home server over SSH; the private settings (`SERWER` ssh host name, `DOMENA`, `PORT_PUBLICZNY`) live in `mise.local.toml` and the server details in `CLAUDE.local.md`, both kept out of git. Two Docker containers on the network `gry`, both `--restart unless-stopped`:
  - `statki` (`node:22-alpine`) runs `serwer.js` from `/srv/statki` (mounted read-only) on internal port 8081 with `PUBLICZNY_ADRES` set to `https://$DOMENA:$PORT_PUBLICZNY`; it publishes no port. Recreated only when `serwer.js`/`zasady.js` changed, the address changed, or it is not running; otherwise browsers just reload and the running game continues.
  - `caddy` (`caddy:2-alpine`) with `wdrozenie/Caddyfile` (copied to `/srv/caddy/Caddyfile`, reloaded on each deploy; `{$DOMENA}` and `{$PORT_PUBLICZNY}` come from the container environment) terminates HTTPS and proxies to `statki:8081`. It obtains and renews its own Let's Encrypt certificate with the HTTP-01 challenge on port 80. Browsers force HTTPS on `.dev` domains, so plain HTTP is not an option there. A new game on the same server = one more site block in the Caddyfile on its own port, published on the `caddy` container.
  - The server reads `PORT` and `PUBLICZNY_ADRES` from the environment.
  - Everything in `/srv/statki` is served to the public, so the deploy leaves out `wdrozenie/`, `.claude/`, `CLAUDE.local.md` and `mise.local.toml`.
- There is no single-player mode: opened from disk, `index.html` only says to start the server.

## Code structure

HTML elements instead of a canvas (a board game needs crisp grids and buttons that work the same with a mouse and a finger). The server decides everything; the browser only draws what the server sends and sends the player's moves.

- `zasady.js` - rules shared by browser and server (`module.exports` when loaded by Node): `TRYBY` (game types: `nazwa`, `opis`, `rozmiar`, `statki` lengths; add a new type here), `LITERY`, `nazwaPola(pole, rozmiar)` (field = row * rozmiar + column, shown as "B5"), `sasiedzi(pole, rozmiar)`, `zbudujFlote(lista, tryb, calaFlota)` (validates bounds, overlap, touching and, for a full fleet, the ship lengths; returns `{ statki, naPolu }` or null), `losujFlote(tryb)`.
- `awatary.js` - the ten gnomes: `id`, Polish `imie`, inline `svg`. `awatarPoId(id)`. The browser draws the picture; the server only checks the id (`require`, same `module.exports` trick as `zasady.js`). A new id needs a server restart, like a change to the rules.
- `serwer.js` - Node, built-in modules only. State `gra`: `etap` (`poczekalnia` -> `ustawianie` -> `bitwa` -> `koniec`), `tryb` (key of `TRYBY`; `tryb()` and `ilePol()` give the current rules), `gracze` (secret `id`, public `nr`, `imie`, `awatar` id, `online`, `offlineOd`, `widz` spectator who joined mid-game, `gotowy`, `odpadl`, `statki`, `naPolu`, `strzaly` 0 none / 1 miss / 2 hit / 3 sunk), `tura` (nr of the shooter), `dziennik`, `ostatni` (last shot with a growing `numer` and a ready-made `tekst`). Actions arrive as POST `/akcja` `{ id, typ, ... }`: `dolacz` (`imie`, `awatar`), `tryb` (lobby only, clears boards), `start` (drops disconnected players, needs 2+), `ustaw` (full fleet; when all are ready the battle starts with a random player), `strzal`, `usun` (only a player offline for `SEKUNDY_DO_USUNIECIA`; in battle they are marked out, otherwise removed), `nowaGra`, `odNowa` (any joined non-spectator, any stage; a second tap from someone already waiting is ignored). `odNowa` sets `etap` back to `poczekalnia`, clears boards, the turn and the log, and moves every current player plus anyone already waiting into `oczekujacy` (`id`, `imie`, `awatar`) so an idle phone cannot auto-rejoin. `dolacz` removes that id from `oczekujacy`. An unknown avatar id keeps the old one, or a random gnome for a new player. Errors come back as `{ blad }` in Polish. Each browser keeps an `EventSource` on `/wydarzenia?id=` and gets its own `stan` view from `widokDla(id)` (with `tryb`, `trzebaPotwierdzic` when this browser is still in `oczekujacy`, and `oczekujacy`: the other waiting names with `awatar` and `online`, no secret ids): every board as a string of rozmiar² characters (0 water, 1 miss, 2 hit, 3 sunk, 4 own unhit ship, all ships at the end). Also serves the files (no hidden files, nothing outside the folder) and sends `odswiez` on file changes. `.svg` is `image/svg+xml`, `.png` is `image/png`, `.ico` is `image/x-icon`.
- `game.js` - browser. `mojeId` in `localStorage` (prefix `statki-`) makes a reconnect, a reload or a server restart rejoin as the same player under the saved name; if the `EventSource` gives up (`CLOSED`), `polacz()` starts a new one after 2 s. A saved name auto-sends `dolacz` (with `statki-awatar`) when `stan.ja` is 0, except when `stan.trzebaPotwierdzic` is set: then `ekranGram` waits for the Gram! tap. `tryb()` returns the current rules from `stan.tryb`; boards size their grid columns from it. `reaguj()` turns server changes into sounds, the result bubble `#dymek`, vibration when your ship is hit, the "your turn" chime, and `wybuchDo` (the newest shot's cell gets class `wybuch` for one animation). `rysuj()` picks a screen (`ekranImie`, `ekranLaczenie`, `ekranGram`, `ekranPoczekalnia`, `ekranUstawianie`, `ekranBitwa`; `ekranPlik` when opened from disk). The name screen's gnome buttons only change a class, they do not rebuild the board. `zrobPlansze(pola, opcje)` builds a board grid. Placement (`ustawianie`) stays local until "Gotowe": pick a ship, tap a cell, tap a placed ship to take it back, ↻ (or R) rotates, 🎲 random, hover preview on desktop. The preview only recolours existing cells (`klasyPodgladu` from `najedzUstawianie`). Rebuilding the board on that hover makes Safari drop the click: on iPhone a tap fires mouseenter first and the ship never lands, and a click after the preview is lost on desktop Safari too. In battle opponents' boards come first and are clickable on your turn; `strzel` sends one shot at a time.
- `dzwieki.js` - Web Audio sounds: shot whistle, miss splash (`dzwiekPlusk`: low "plum" with a rising bubble, soft falling-pitch noise of the splash, then random quiet droplets via `babelek`), explosion, sinking, turn chime, click.
- `index.html` / `style.css` - all screens, game type buttons (`#tryby`) and rules text in the lobby; boards are `min(92vw, 340px)` wide and wrap, the turn bar sticks to the top on phones. The tab icon is `ikona.svg` (a pen ship on squared paper) with `ikona-32.png`, `favicon.ico` and `ikona-180.png` (apple-touch-icon) so a phone home screen stays sharp. Two looks, switched by the header button and remembered as `statki-wyglad` in `localStorage`. Default `kartka` is a squared notebook sheet: off-white paper, a red margin, light blue grid lines, column letters and row numbers in a handwriting font, ships as one pen outline (`krawedzGora` / `krawedzDol` / `krawedzLewo` / `krawedzPrawo`, added when the board is built), a miss as a small circle, a hit as an X, a sunk ship as a red pen outline with a bigger X. The result bubble sits at the bottom so it does not cover the turn line; the winner line is a yellow highlighter (`koniecGry`). `morze` is the previous sea look: water blue, miss 💦, hit orange ✖, sunk dark red ✖, own ship grey. The newest shot has a yellow outline and a one-time ring animation. The handwriting font is Patrick Hand in `czcionki/` (SIL OFL, `czcionki/OFL.txt`), so it loads with no internet; Segoe Print, Comic Sans and Chalkboard SE are the fallback. `serwer.js` serves `.woff2` as `font/woff2`.

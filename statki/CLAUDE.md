# CLAUDE.md

The rules for talking to Jaś, building and code style are in `../CLAUDE.md`. This file describes only this game.

## The game

Statki: the classic Polish battleship game for the whole family, played together in the same Wi-Fi on phones and computers, with any number of players (at least two). Everyone types a name in the lobby, anyone presses Start, each player places a fleet on their own 10x10 board, then players shoot in turn at any opponent's board. A hit (or a sunk ship) gives another shot, a miss passes the turn. A player who loses all ships is out; the last one with ships wins. Everyone sees every board's shots; only your own unhit ships are visible to you until the game ends, when all ships are revealed.

Two board sizes, picked by anyone in the lobby: Klasyczna (10x10 board; one 4-mast, two 3-masts, three 2-masts, four 1-masts, Polish rules) and Szybka (7x7 board; ships 3, 2, 2, 1, 1) for a quick game. Ships may not touch, not even at corners. Water around a sunk ship is marked automatically.

Two ways to win, picked inside one lobby (everyone in that lobby sees the same choice; another code keeps its own). Klasycznie is the default and is unchanged: a hit gives another shot, a miss passes the turn, a player with no ships is out, the last fleet wins. Na punkty: the same shooting (a hit still gives another shot; one round is one such turn for every player still in the game), 1 point per hit cell plus a bonus equal to the ship's length when it sinks, so a 1-mast is 2 points and a 4-mast is 8. Auto-marked water around a wreck is not a shot and scores nothing. The game lasts 5, 10 (default) or 15 rounds, or ends at once when only one fleet still has ships. A sunk fleet is not a target anymore, but that player keeps shooting and scoring until the game ends. Highest score wins, even with no ships left. A tie on points goes to better accuracy (hits divided by shots fired). If accuracy ties too, they share the place. `mise run test` checks the rules.

If someone joined but is not really playing, any real player (not a spectator) can press "Zacznij od nowa" in the lobby, while placing ships, or during the battle. A box then asks "Tak, od nowa" (or "Nie"), so it is not an accident. Every connected player is dropped from the round and sees the Gram! screen; only those who tap Gram! enter the lobby. The lobby and the ship-placing screen list who is still pending. "Nowa gra" at the end still keeps the connected players in the same lobby, as before. "Wyjdź" leaves this lobby and goes back to the start screen (not during a battle, unless you are only watching).

A friendly computer opponent ("Robot", the Mądrala gnome) exists only on the preview server, never on the normal home game. The start screen then shows "Graj z robotem". That button opens a lobby that already has the robot. The robot places a random legal fleet when Start is pressed and, on its turn, waits a short moment (`STATKI_ROBOT_PAUZA` milliseconds, default 700, tests use 0) then shoots. It mostly picks a random empty cell (`SZANSA_POLOWANIA` is 0.2). Only sometimes, after a hit that has not sunk the ship, it aims at an orthogonal neighbour (along the line if the hits already make one); the rest of the time it forgets and shoots somewhere else. It never reads hidden ships. A miss passes the turn, a hit lets it shoot again, same as a person. Its ships stay hidden. It counts as a connected player, so one child can press Start. "Zacznij od nowa" drops the people onto the Gram! screen and sits the robot back down; it does not have to press Gram!. A client cannot act with the robot's id. The button and the `grajZRobotem` action are off unless `podgladZRobotem` in `robot.js` is true: `STATKI_PODGLAD=1`, or `PORT` is `8090`, or `PUBLICZNY_ADRES` ends with `:50090` (a slash, `?` or `#` may follow). Anything else, including production on public port 50081, leaves `stan.robot` false, hides the button, and answers "Tu nie ma robota". The preview container is started outside this repo as `node:22-alpine node serwer.js` with only `PORT=8090` and a `PUBLICZNY_ADRES` that ends with `:50090`, so the robot turns on there even without `STATKI_PODGLAD`. Production does not set those values.

Several games run on this one server at the same time. The start screen (`ekranStart`) has "Nowa gra" and "Dołącz kodem". When the robot is enabled it also has "Graj z robotem". "Nowa gra" can take an own code (letters and digits, 3–8 characters; Polish letters are folded, so Jaś1 becomes jas1; upper and lower case are the same). An empty field gets a short word or name from `SLOWA_KODOW` plus a digit 1–9, for example jas1 or ala3. If that code is already a lobby, the server says so in simple Polish and does not open the other game. The code is shown big in the lobby (and spelled underneath), in the header during the game, and as a link `?kod=jas1`. A missing or bad code gets a short Polish message. Lobbies do not share players, boards, turns, the win mode (`sposob`, rounds and scores), the restart list or the log. A lobby with nobody connected is deleted after 15 minutes so a small computer (Raspberry Pi 2) does not keep old games. `SEKUNDY_PUSTEGO_LOBBY` overrides that for tests. At most 40 lobbies.

On the name screen each player picks one of ten original gnomes. Each has its own colour, a thick ring in a darker shade of that colour (so the frame still shows on the cream notebook page), and one big prop, so they stay easy to tell apart even at the small size on a phone: Śpioch (purple, nightcap, yellow pompon and a pillow), Łasuch (pink, cupcake), Kucharz (red, tall white chef hat), Mądrala (green, big glasses and an open book), Siłacz (orange, red dumbbell), Maruda (grey, frown and crossed arms), Wesołek (yellow, huge smile and a wave), Malarz (teal, red beret and a paint palette), Pirat (dark, red bandana and an eyepatch), Kapitan (blue, white captain cap with a black brim). They are drawn in the game, not taken from any cartoon. The gnome's name sits under the picture on the name screen, and beside the picture in the lobby, on each board and on the end-screen cards and ranking, where there is room. The turn line and the live score chips stay picture-only, so the bar does not get crowded. The choice is remembered on the device as `statki-awatar`. If nothing was saved, the browser picks one at random. Two players may pick the same one. The face is sent with `dolacz` and shown in the header, the Gram! screen, the lobby, the waiting list, while placing ships, on each board in the battle, on the winner line, on the points scoreboard and final ranking, and on the end-screen statistics.

When the battle ends, the end screen shows statistics kept on the server for that lobby only, in both Klasycznie and Na punkty: who shot at whom, shots, hits, misses, accuracy, which ships each player sank and whose, and awards (Snajper for the best accuracy, Pechowiec for the most misses, Seria for the longest run of hits, Pogromca for the most ships sunk). Na punkty also shows the points next to the accuracy. Each line shows that lobby's gnome. A shot in one code does not change another code. Rings of water drawn around a sunk ship are not counted as shots and score nothing. The numbers reset on Start, on "Nowa gra", and on "Zacznij od nowa" inside that lobby.

## How to run

- `mise run serwer` - runs `serwer.js` on port 8081 (Kraina Wiśni uses 8080, so both can run) for the whole home network, opens the game in the browser and prints the address for phones. Every saved file (except `serwer.js`) reloads the page in all browsers; the game itself lives on the server and continues. Changing `serwer.js` needs a server restart, which ends the current game.
- `mise run wdroz` - deploys to a home server over SSH; the private settings (`SERWER` ssh host name, `DOMENA`, `PORT_PUBLICZNY`) live in `mise.local.toml` and the server details in `CLAUDE.local.md`, both kept out of git. Two Docker containers on the network `gry`, both `--restart unless-stopped`:
  - `statki` (`node:22-alpine`) runs `serwer.js` from `/srv/statki` (mounted read-only) on internal port 8081 with `PUBLICZNY_ADRES` set to `https://$DOMENA:$PORT_PUBLICZNY`; it publishes no port. Recreated only when `serwer.js`/`zasady.js` changed, the address changed, or it is not running; otherwise browsers just reload and the running game continues.
  - `caddy` (`caddy:2-alpine`) with `wdrozenie/Caddyfile` (copied to `/srv/caddy/Caddyfile`, reloaded on each deploy; `{$DOMENA}` and `{$PORT_PUBLICZNY}` come from the container environment) terminates HTTPS and proxies to `statki:8081`. It obtains and renews its own Let's Encrypt certificate with the HTTP-01 challenge on port 80. Browsers force HTTPS on `.dev` domains, so plain HTTP is not an option there. A new game on the same server = one more site block in the Caddyfile on its own port, published on the `caddy` container.
  - The server reads `PORT`, `PUBLICZNY_ADRES` and optional `SEKUNDY_PUSTEGO_LOBBY` from the environment. The robot button is not part of this deploy: production's address does not end with `:50090` and its port is not 8090, and `STATKI_PODGLAD` is unset, so the option stays hidden.
  - Everything in `/srv/statki` is served to the public, so the deploy leaves out `wdrozenie/`, `.claude/`, `CLAUDE.local.md` and `mise.local.toml`.
- `mise run test` - checks points mode (hits, sinking bonus, rounds, a sunk fleet that still scores) inside a lobby, the robot flag (off by default, on for `STATKI_PODGLAD`, port 8090 and an address ending in `:50090`), and that a preview game against the robot hides its ships and gets a robot shot.
- `mise run testy` - checks that two lobbies do not mix (joins, gnomes, shots, restart, a wrong code, icons, and that an empty lobby disappears), and that end-of-game stats, points and gnomes stay inside their own code.
- Opened from disk, `index.html` only says to start the server. A solo game needs the preview robot button above.

## Code structure

HTML elements instead of a canvas (a board game needs crisp grids and buttons that work the same with a mouse and a finger). The server decides everything; the browser only draws what the server sends and sends the player's moves.

- `zasady.js` - rules shared by browser and server (`module.exports` when loaded by Node): `TRYBY` (board sizes: `nazwa`, `opis`, `rozmiar`, `statki` lengths; add a new type here), `SPOSOBY` (`klasyczny` / `punkty`), `RUNDY_DO_WYBORU` and `RUNDY_DOMYSLNIE`, `punktyZaStrzal(wynik, dlugosc)`, `ranking(lista)` (points, then accuracy, shared place on a full tie), `LITERY`, `nazwaPola(pole, rozmiar)` (field = row * rozmiar + column, shown as "B5"), `sasiedzi(pole, rozmiar)`, `zbudujFlote(lista, tryb, calaFlota)` (validates bounds, overlap, touching and, for a full fleet, the ship lengths; returns `{ statki, naPolu }` or null), `losujFlote(tryb)`. Also the lobby code: `SLOWA_KODOW`, `oczyscKod(tekst)` (lowercase, strips Polish diacritics, keeps letters and digits), `kodWygladaDobrze(kod)` (3–8 of those), `losujKodGry(zajete)` (word plus a digit 1–9 that is not already taken). `test.js` checks points mode inside a lobby (`mise run test`).
- `awatary.js` - the ten gnomes: `id`, Polish `imie`, inline `svg`. `awatarPoId(id)`. Each picture is a coloured circle with a thick ring in a darker shade of that colour and one big prop (nightcap, cake, chef hat, glasses, dumbbell, frown, smile, beret, eyepatch, captain cap) so it still reads at 32 px. The browser draws the picture; the server only checks the id (`require`, same `module.exports` trick as `zasady.js`). A new id needs a server restart, like a change to the rules. The picture stays inside one lobby's player, never on the whole server.
- `robot.js` - shared by the server and `test.js` (`module.exports`): `podgladZRobotem(env, port, adres)`, `wybierzPoleRobota(strzaly, rozmiar)`, `polaPolowania`, `czyPoluje`. Not loaded in the browser.
- `serwer.js` - Node, built-in modules only, plus `zasady.js`, `awatary.js` and `robot.js`. Many lobbies: `lobby[kod]` is one game. `pustaGra(kod)` is that game's whole state, and every rule function takes this `gra`, so scores, the gnome and the win mode stay inside the lobby instead of leaking across games. `gra`: `kod`, `zRobotem` (this lobby was opened with the robot; only when the preview flag is on), `etap` (`poczekalnia` -> `ustawianie` -> `bitwa` -> `koniec`), `tryb` (key of `TRYBY`; `tryb(gra)` and `ilePol(gra)` give the current board), `sposob` (`klasyczny` or `punkty`, default `klasyczny`), `ileRund`, `runda`, `kolejka` (whose turn is still left this round, points mode only), `gracze` (secret `id`, public `nr`, `imie`, `awatar` id, `online`, `offlineOd`, `widz` spectator who joined mid-game, `robot` for the computer player, `gotowy`, `odpadl`, `statki`, `naPolu`, `strzaly` 0 none / 1 miss / 2 hit / 3 sunk, `stat` with this lobby's shots, hits, misses, best hit streak, ships sunk and a who→whom tally, and for points `punkty`, `trafienia`, `oddane`), `oczekujacy`, `tura` (nr of the shooter), `dziennik`, `ostatni` (last shot with a growing `numer` and a ready-made `tekst`), `numerStrzalu`, `nastepnyNumer` (per lobby), `sluchacze` (this lobby's open connections only), `ostatnio` (for cleanup). Actions arrive as POST `/akcja` `{ id, kod, typ, ... }`: `noweLobby` (returns `{ kod }`), `grajZRobotem` (same, but only if the preview flag is on; marks `zRobotem` and seats the robot), `sprawdzKod`, then inside that lobby `dolacz` (`imie`, `awatar`), `tryb` (lobby only, clears boards), `sposob` and `rundy` (this lobby only; rounds must be 5, 10 or 15), `start` (drops disconnected players, needs 2+), `ustaw` (full fleet; when all are ready the battle starts with a random player), `strzal`, `usun` (only a player offline for `SEKUNDY_DO_USUNIECIA`; in battle they are marked out, otherwise removed), `nowaGra` (same lobby, after the end), `odNowa` (any joined non-spectator, any stage; a second tap from someone already waiting is ignored), `wyjdz` (leave this lobby; during a battle only a spectator may). `odNowa` sets `etap` back to `poczekalnia`, clears boards, the turn and the log, and moves every current human player plus anyone already waiting into `oczekujacy` (`id`, `imie`, `awatar`) so an idle phone cannot auto-rejoin. The robot is not put on that list; if `zRobotem` it is seated again. It keeps `tryb`, `sposob`, `ileRund` and `zRobotem`. `dolacz` removes that id from `oczekujacy`. An unknown avatar id keeps the old one, or a random gnome for a new player. In points mode a sunk fleet does not set `odpadl` and that player stays in the turn order; `odpadl` is only for a player removed while offline. Errors come back as `{ blad }` in Polish. Each browser keeps an `EventSource` on `/wydarzenia?id=&kod=` and gets its own `stan` view from `widokDla(gra, id)` (with `kod`, `tryb`, `sposob`, `runda`, `ileRund`, `ranking` when this lobby plays for points, `trzebaPotwierdzic` when this browser is still in `oczekujacy`, and `oczekujacy`: the other waiting names with `awatar` and `online`, no secret ids): every board as a string of rozmiar² characters (0 water, 1 miss, 2 hit, 3 sunk, 4 own unhit ship, all ships at the end). `statystyki` is null until this lobby's `koniec`, then it is that lobby's public numbers, awards, gnome ids and, in points mode, points (no secret ids). `wyczyscPlansze` clears `stat` and the points, so Start and Nowa gra reset this lobby's tally; Zacznij od nowa drops this lobby's players and the tally with them. No code, or a code that is not a live lobby, gets `{ ekran: "start", robot }` or `{ brakGry, kod, tekst, robot }` (`robot` is whether this server may offer the computer opponent) and still receives `odswiez`. `widokDla` also sends `robot` and `zRobotem`, and each public player has `robot: true` for the computer. The same player id can sit in two lobbies at once (two browser windows). Also serves the files (no hidden files, nothing outside the folder) and sends `odswiez` on file changes. `.svg` is `image/svg+xml`, `.png` is `image/png`, `.ico` is `image/x-icon`. Empty lobbies are removed by `posprzataj` (nobody connected for `SEKUNDY_PUSTEJ_GRY`, default 15 minutes).
- `game.js` - browser. `mojeId` in `localStorage` (prefix `statki-`) makes a reconnect, a reload or a server restart rejoin as the same player under the saved name; if the `EventSource` gives up (`CLOSED`), `polacz()` starts a new one after 2 s. A saved name auto-sends `dolacz` (with `statki-awatar`) when `stan.ja` is 0, except when `stan.trzebaPotwierdzic` is set: then `ekranGram` waits for the Gram! tap. `tryb()` returns the current rules from `stan.tryb`; boards size their grid columns from it. `reaguj()` turns server changes into sounds, the result bubble `#dymek`, vibration when your ship is hit, the "your turn" chime, and `wybuchDo` (the newest shot's cell gets class `wybuch` for one animation). `kodGry` comes from `?kod=` (cleaned by `oczyscKod`). No code: `ekranStart` ("Nowa gra" creates a lobby and opens `?kod=`, "Graj z robotem" only when `stan.robot` is true, "Dołącz kodem" checks the code first, "Wróć do gry" uses the last code in `localStorage`). `wyslij` adds `kod`. A saved name still auto-sends `dolacz` only inside a real lobby, and not when `stan.trzebaPotwierdzic` is set. `rysuj()` picks a screen (`ekranStart`, `ekranImie`, `ekranLaczenie`, `ekranGram`, `ekranPoczekalnia`, `ekranUstawianie`, `ekranBitwa`; `ekranPlik` when opened from disk). The name screen's gnome buttons only change a class, they do not rebuild the board. The lobby shows `#kodDuzy`, the spelled letters, the join link and each player's gnome; `#kodWNaglowku` shows the code once you are in. Points mode draws `#sposoby` and `#rundy` in that lobby and `rysujTablice()` from `stan.ranking` (a small gnome next to each score, and again on the final ranking); the turn line is `#turaNapis` so it does not wipe `#tablica`. A sunk fleet is not clickable. `zrobPlansze(pola, opcje)` builds a board grid and, for every visible ship cell (own ship, hit or sunk), an inline SVG seen from above: pointed bow at the start of the ship (left, or top when vertical), rounded stern at the other end, portholes, and on longer ships a cabin with a funnel on the cell before the stern. A 1-cell ship is a little boat. `rolaKawalka` / `opisKawalka` pick the piece. Vertical ships are the same drawing rotated 90 degrees. Placement (`ustawianie`) stays local until "Gotowe": pick a ship, tap a cell, tap a placed ship to take it back, ↻ (or R) rotates, 🎲 random, hover preview on desktop. The preview only recolours existing cells and swaps the ship drawing (`klasyPodgladu` and `opisyPodgladu` from `najedzUstawianie`). Rebuilding the board on that hover makes Safari drop the click: on iPhone a tap fires mouseenter first and the ship never lands, and a click after the preview is lost on desktop Safari too. In battle opponents' boards come first and are clickable on your turn; `strzel` sends one shot at a time. On the end screen `rysujStatystyki` fills `#statystyki` from this lobby's `stan.statystyki` (awards, who-shot-whom table and a card per player, each with that lobby's gnome; Na punkty adds the points next to the accuracy). Award names live in `NAZWY_ODZNAK`.
- `dzwieki.js` - Web Audio sounds, synthesized in the browser (no sound files). A shot is a short naval cannon (`dzwiekStrzalu`, under about 0.8 s): a falling low sine boom (plus a lower sub layer), a very short band-passed noise crack so the attack is not a piercing snap, a low-passed rumble tail, then a quieter delayed copy as an echo over the water. A miss is `dzwiekPlusk`: a low falling body, a band-pass noise splash that drops in pitch ("sploosh"), and a few quiet droplets via `babelek`. A hit is `dzwiekWybuch`: a short deep boom, a wooden thunk and a quiet metal clang, with no fire or scream. Sinking is `dzwiekZatopienie`: three bubbling "glu" notes, a little water, then a short do-mi-sol tune. Also the turn chime and a click. Someone else's shot (a friend or the robot) plays the cannon as well as the splash or ding; your own click already played the cannon, so it is not repeated. `GLOSNOSC_ARMATA`, `GLOSNOSC_PLUSK`, `GLOSNOSC_TRAFIENIE` and `GLOSNOSC_ZATOPIENIE` at the top scale those four (1 is the normal moderate level, 0 turns one off).
- `index.html` / `style.css` - all screens, board buttons (`#tryby`), who-wins buttons (`#sposoby`) and, only for Na punkty, round buttons (`#rundy`, hidden in the classic lobby) plus rules text; during a points battle `#tablica` (inside the sticky `#tura` bar, under `#turaNapis`) shows the round, the gnomes and the live scores, and at the end `#ranking` lists places with a gnome, points and hits out of shots. Boards are `min(92vw, 340px)` wide and wrap, the turn bar sticks to the top on phones. The tab icon is `ikona.svg` (a pen ship on squared paper) with `ikona-32.png`, `favicon.ico` and `ikona-180.png` (apple-touch-icon) so a phone home screen stays sharp. Two looks, switched by the header button and remembered as `statki-wyglad` in `localStorage`. Default is `morze` unless the saved value is `kartka`. `morze` water cells are navy (`#0b2144`), and the page behind them is a dark navy gradient. Across the whole sea sits one still picture, `obrazki/pagorki.svg`: tall jagged waves like after a storm, darker troughs, lighter wave faces and white foam on the crests (blobs and short spray). It does not move (no animation). `zrobPlansze` sets `--morze` to the board size and `--kol` / `--wiersz` on each cell, and the CSS slices that one picture so neighbouring squares continue the same hills. Hits and sunk ships keep their own colours so the board stays easy to read; own ships and misses sit on the picture, with the ship drawing on top. The board gap is a light line so every square stays visible, and column letters and row numbers are white on a darker blue. `kartka` is a squared notebook sheet: off-white paper, a red margin, light blue grid lines, column letters and row numbers in a handwriting font, ships as a pen drawing of a hull (pointed bow, deck line, portholes, cabin, funnel, rounded stern; the SVG classes are `kadlub`, `linia`, `okno`, `kabina`, `komin`), a miss as a small circle, a hit as an X drawn over the ship, a sunk ship in red pen with a bigger X. `krawedzGora` / `krawedzDol` / `krawedzLewo` / `krawedzPrawo` are still added when the board is built. The result bubble sits at the bottom so it does not cover the turn line; the winner line is a yellow highlighter (`koniecGry`). The end-screen stats (`#statystyki`) sit on the same sheet: dashed blue frame, highlighter title, pastel award chips, a scrolling who→whom table and a card per player, with the lobby's gnomes beside the names. In the sea theme the same block is a dark translucent card with the same chips. `morze` is the sea look and the one you see first: navy water with those still storm waves and foam, the same hull shapes filled in like a toy boat (blue-grey hull, pale cabin, yellow funnel, light portholes), miss 💦, hit as a soft peach square with ✖, sunk as a dusty hull with ✖, own ship sitting on the water. No fire. The newest shot has a yellow outline and a one-time ring animation. The handwriting font is Patrick Hand in `czcionki/` (SIL OFL, `czcionki/OFL.txt`), so it loads with no internet; Segoe Print, Comic Sans and Chalkboard SE are the fallback. `serwer.js` serves `.woff2` as `font/woff2`.

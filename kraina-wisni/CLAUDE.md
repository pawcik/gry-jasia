# CLAUDE.md

The rules for talking to Jaś, building and code style are in `../CLAUDE.md`. This file describes only this game.

## The game

Kraina Wiśni: an open world in old Japan, seen from above at an angle like an arena game. The hero is an original fox-spirit kid (fox ears, big fluffy tail, white kimono, red hakama, katana, a small blue spirit flame circling around). The game is made for a phone held in landscape: the left stick walks, the right stick aims the sword (drag to aim, release to slash, quick tap = slash forward). Right now the world has a training yard with straw dummies, a village, a river with an arched bridge, rice fields, a red gate, stone lanterns, a pagoda, a bamboo grove, cherry trees and pines; there are no enemies or goals yet.

Multiplayer: everyone on the same Wi-Fi who opens the server address types a name, picks a fox colour and sees the other players walking and slashing, with names above their heads. Jaś plays on the phone, his dad on the computer.

## How to run

- `mise run serwer` - runs `serwer.js` on port 8080 for the whole home network and opens the game in the browser. It prints the address to open on a phone in the same Wi-Fi. Use it while developing (every saved file reloads the game in all connected browsers), for phone testing (touch controls only exist on a touch screen) and for playing together.
- `mise run graj` - just opens `index.html` from disk: single player, no server, no names.

## Code structure

3D with Three.js r128 (`biblioteki/three.min.js`, global `THREE`, same version as Monkey World). Coordinates: x east, z south, y up; the camera always looks north, so "up" on a stick means -z. A direction angle `kat` points along `(sin kat, cos kat)` in (x, z), and models face +z when `rotation.y = 0`.

The server is plain Node (`serwer.js`, only built-in modules); the game in the browser still needs no build and also runs from `index.html` on disk.

- `swiat.js` - world constants at the top (`GRANICA` world edge, start, colours, tree counts, river and bridge position). Helpers: `kolorek` (sRGB colour to linear, the renderer uses sRGB output), `farba` (cached cartoon `MeshToonMaterial` per colour), `swiecaca` (unlit `MeshBasicMaterial`), `klocek(shape, colour or material, x, y, z, parent)`, `plaski` (flat ground patch), `zrobGromade` (one `InstancedMesh` with per-instance colour on the white `farbaGromady`; used for trees, grass, rice, rocks, bamboo, border pines to keep draw calls low on phones), seeded `losuj`/`losujOd`/`wybierz` so the world is the same every time, `roznicaKatow`. Collisions: `kola` (circles) and `prostokaty` (rectangles, incl. the river except the bridge gap); `moznaStanac(x, z, promien)`; `zarezerwowane` areas (paths, fields, river, yards) where no trees or grass are placed (`wolneMiejsce`). `wysokoscZiemi` lifts the hero onto the bridge arch. `zbudujSwiat()` builds everything; `ruszPlatki()` moves the falling cherry petals (`THREE.Points`) around the hero.
- `sterowanie.js` - touch sticks (`lewyDrazek`, `prawyDrazek`, HTML divs that jump under the finger), keyboard (`klawisze`) and mouse (`mysz`). `kierunekRuchu()` returns the walk direction, `celowanie()` the current aim (angle, `"mysz"` or null), and `chceCiac` is set when a slash is requested (`"przod"`, `"mysz"` or an angle). Adds class `dotykowy` to `body` on touch devices. The first touch tries fullscreen and landscape lock once; after that only the ⛶ button (top-left, `przelaczCalyEkran`, also key F) enters or leaves fullscreen, so the player can always get out.
- `bohater.js` - hero constants at the top (speed, sword reach and arc, slash timing, colours). A "postać" is any fox on screen (our `bohater` or another player): `x`, `z`, `kat`, `predkosc`, `krokChodu`, `ciecie`, `katCiecia`, `liczbaCiec`, `model`, `slad`, `imie`, `kolor`. `zrobPostac`, `zmienWyglad` (rebuilds the model in a fur colour with a name sprite from `zrobEtykiete`), `usunPostac`. `zrobLiska(kolorFutra)` builds the model with pivots (`nogi`, `ramie`/`reka`/`miecz` right arm, `lewaReka`, `glowa`, `uszy`, `ogon`, `ognik`). `ruszBohatera()` walks with sliding along obstacles, starts slashes (`liczbaCiec++`), calls `trafKukly` at `MOMENT_TRAFIENIA`, shows the aim arc `wskaznik`; `pokazSlad(postac)` and `animujPostac(postac)` work for every fox.
- `kukly.js` - straw training dummies (`MIEJSCA_KUKIEL`): `trafKukly(postac, kat, liczyPunkty)` hits those inside the sword arc (only our own hits count), `ruszKukly()` wobbles and flashes them; `trafienia` counts hits for the HUD.
- `siec.js` - multiplayer client, active only when the page comes from the server (`siec.wlaczona`). Name screen `#logowanie` (name + fur colour from `KOLORY_LISKOW`), saved in `localStorage` under `NAZWA_ZAPISU` so a reload rejoins at once; the ✏️ button reopens it. `polacz()` opens an `EventSource` on `/wydarzenia` (events `gracze` with the full player list, `odswiez` for live reload). `wyslijStan()` POSTs our position, angle and slash counter to `/ruch` every 4 steps. `aktualizujInnych` creates, updates and removes other players in `siec.inni`; a grown `liczbaCiec` replays their slash. `ruszInnych()` glides them toward the last received position. Players walk through each other.
- `serwer.js` - Node server, no packages: serves the game files (no hidden files, nothing outside the folder, no caching), keeps players in memory, broadcasts the list 20 times per second when something changed, drops a player when their connection closes, and sends `odswiez` to everyone when a file in the folder changes.
- `dzwieki.js` - Web Audio sounds (`dzwiekCiecia`, `dzwiekStukniecia`), unlocked by `wlaczDzwieki()` on the first touch, click or key.
- `game.js` - renderer (shadows, sRGB), scene, fog, hemisphere light and the sun that follows the hero, camera high behind the hero (`KAMERA_WYSOKO`, `KAMERA_Z_TYLU`, `ustawKamere`), `katDoMyszy()`, pause (P), fixed-step loop: `krokGry()` runs `ruszBohatera`, `ruszInnych`, `wyslijStan` (every 4th step), `ruszKukly`, `ruszPlatki`, `ustawKamere` 60 times per second.
- `index.html` / `style.css` - full-window canvas, HUD (title, 🎯 hits, 👥 player names), ✏️ button, name screen, pause text, the two sticks, the "rotate your phone" screen for portrait, keyboard hint (hidden on touch). Touches and clicks on the name screen and the ✏️ button are not game controls (`wOkienku` in `sterowanie.js`), and keys typed into the name field are ignored by the game. Script order: three, dzwieki, swiat, sterowanie, bohater, kukly, siec, game.
